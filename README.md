# Notes

`Notes` - консольная система заметок для ИТ-инфраструктуры VPN-сервиса.


В решении есть три проекта:

- `NotesApp` - основное консольное приложение;
- `Watcher` - сбор статистики CPU/RAM/HDD;
- `Installer` - установка обновления из zip-архива.

## Роли

- `user` - создает и ведет свои заметки.
- `admin` - управляет пользователями, смотрит заметки выбранного пользователя, логи и обновления.
- `analyst` - смотрит статистику watcher-а.

## Запуск

После запуска `NotesApp` открывается меню:

```text
1 - Войти
2 - Зарегистрироваться
0 - Выход
```

После входа команды вводятся в строке:

```text
notes>
```

## Общие команды

- `help` - показывает команды для текущей роли.
- `version` - показывает версию приложения.
- `logout` - выходит из учетной записи.
- `exit` - закрывает приложение.

## Заметки

Доступны ролям `user` и `admin`.

- `addNote <текст>` - добавляет заметку.
- `listNotes` - показывает свои заметки.
- `editNote <id> <текст>` - изменяет заметку.
- `deleteNote <id>` - удаляет заметку.

Пример:

```text
addNote Проверить шлюз
```

Пример вывода `listNotes`:

```text
1 | 2026-05-26 14:40 | Проверить шлюз
```

## Администратор

Доступно роли `admin`.

- `createUser <логин> <пароль> <роль>` - создает пользователя.
- `listUsers` - показывает пользователей.
- `listUserNotes <логин>` - показывает заметки выбранного пользователя.
- `showLogs <количество>` - показывает последние записи логов.
- `blockUser <логин>` - блокирует пользователя.
- `unblockUser <логин>` - разблокирует пользователя.
- `deleteUser <логин>` - удаляет пользователя.
- `updateCheck` - проверяет наличие обновлений.
- `updateInstall` - скачивает и запускает установку обновления.

Роли для `createUser`: `user`, `admin`, `analyst`.

Примеры команд:

```text
createUser analyst1 123456 analyst
listUserNotes admin1
showLogs 10
blockUser admin1
```

Пример вывода `listUserNotes admin1`:

```text
3 | admin1 | 2026-05-26 16:15 | Проверить БД
```

Пример вывода `showLogs 2`:

```text
2 | 2026-05-26 15:30:20 | admin | create_user | analyst1 | Создан пользователь с ролью analyst.
1 | 2026-05-26 15:28:41 | admin | login_success | admin | Пользователь вошел в систему.
```

Версия приложения берется из `NotesApp/Properties/AssemblyInfo.cs`, а репозиторий для обновлений - из `NotesApp/notes.yml`.

## Watcher

Доступно ролям `admin` и `analyst`.

Watcher собирает статистику устройства: загрузку CPU, использование RAM и диска.

- `startWatcher [секунды]` - запускает watcher на текущем компьютере.
- `listDevices` - показывает устройства, отправлявшие статистику.
- `showMetrics <deviceId>` - показывает последние метрики устройства.

Примеры команд:

```text
startWatcher 5
listDevices
showMetrics 1
```

Пример вывода `listDevices`:

```text
1 | DESKTOP-7NGSORH | последний контакт: 2026-05-26 11:30
2 | DESKTOP-9JROMKL | последний контакт: 2026-05-26 12:30
```

Пример вывода `showMetrics 1`:

```text
2026-05-26 11:30:15 | CPU: 12.00% | RAM: 63.45% | HDD: 41.20%
2026-05-26 11:29:15 | CPU: 18.00% | RAM: 62.90% | HDD: 41.20%
```
